# FinTrack – Personal Finance Tracker

## Overview

FinTrack is a modern and responsive Personal Finance Tracker web application that helps users manage their daily expenses, monitor budgets, and analyze spending habits efficiently.

Users can:
- Add and manage expenses
- Set monthly budgets
- Filter and search transactions
- View expense analytics
- Export data as CSV
- Use Dark/Light Mode

---

# Live Demo

FinTrack is Live at: https://personalfinancetracker8.netlify.app/

---

# Objective

The objective of FinTrack is to provide a simple and user-friendly platform for tracking personal finances and improving budget management skills using an interactive dashboard.

# How to Run the Project

## Clone the Repository

```bash

```

## Open the Project

- Open the project folder
- Run `index.html` in your browser

- Enter your name
- Proceed to the dashboard
- Start managing your expenses
